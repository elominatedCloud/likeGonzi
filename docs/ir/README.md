### 진술 슬라이드를 6장 줄였다

5분 발표에 33장은 장당 9초라 너무 빡빡했다. 한 줄짜리 슬라이드를 **인접한 증거 슬라이드의 헤드라인으로 흡수**했다.
*멘트 → 다음 장 증명*이 아니라 **한 장에서 멘트와 증명이 같이** 있게 된다.

```
럭셔리는 새것일 때… + 그래서 쓰지 않습니다   → 한 장으로
매일 쓰면 상합니다                          → 3분류 슬라이드 헤드라인
지금 이 문제를 푸는 브랜드는 없습니다          → 근거 슬라이드 하단
사진을 올리면 AI가 기록합니다                → AI 3열 헤드라인
MCM이 이미 가진 것을 그대로 씁니다            → 여권 헤드라인
저희 자리는 DPP 위층입니다                   → 경쟁 헤드라인
```

남긴 진술은 넷이다 — 질문(02), 매일 드는 가방(10), 내 역사이자 MCM의 역사(15), 마무리(29).

### 수선 포지션 — 두 갈래

```
수선 접수 (공통)  부위 탭 + 증상 + 사진 → 견적
        │
   ┌────┴────┐
 복원        REMADE
 원래대로     흠 위에 무늬를
 기본        선택 · 프리미엄
```

둘 다 MCM 공식 유료 상품이고 접수 흐름은 하나다.
**모든 수선이 REMADE는 아니다** — 대부분은 복원을 원한다.
선택 자체가 기록에 남는다.

### 구현 수준 — 슬라이드에서 뺐다

전용 슬라이드를 두면 흐름이 끊긴다. **발표 노트(마지막 장)에 넣어 Q&A로만 답한다.**
구현/로드맵 표기는 04번 네 축과 26번 여권 화면에 인라인으로 남아 있다.

| | |
|---|---|
| **구현** | AI Story·Recap · REMADE 시안 · **GS1 Digital Link** · **EU ESPR 여권 항목** · 수선 접수 · 상황 데이터 집계 |
| **규칙** | Care Score · 수선 견적 (AI 아님. 견적은 AI가 설명문만) |
| **데모** | 여권 수치 · 결제 |
| **연동 예정** | Aura 원장 기록 |
| **로드맵** | 캠페인 QR · 소유권 이전 |

제품 상태를 AI가 판정하지 않는다. **어디에 안 쓰는지도 슬라이드에 적었다.**

### 디지털 제품 여권 — 검증됨

스캔해서 도착하는 자리가 제품 상세라, 새 화면 대신 인증 정보를 여권으로 키웠다.

```
GS1 Digital Link  /01/{gtin}/21/{serial}
  /01/2900000000018/21/MWKCSVE01C0002  →  /start?tag=UNIT-STARK-0002
  /01/2900000000018/21/NOPE            →  /start?status=error
  /01/999/21/x                         →  /start?status=error
```

GTIN 체크디지트 유효(`2·1 + 9·3 + 1·3 = 32 → 8`). GS1 **290 제한 유통 대역**이라 실제 등록 상품과 충돌하지 않는다.

**두 곳을 일부러 막아뒀다.**
`dpp_data_source`가 `demo`면 화면에 *"소재·재활용·수리가능성 수치는 시연용 가정치입니다"*가 함께 뜬다.
앵커 상태는 `not_anchored`이고 화면에 *"블록체인 원장 기록은 아직 연결되지 않았습니다"*라고 적는다.
뒷받침 못 하는 숫자를 사실처럼 보여주지 않는다.

### REMADE는 실제로 돕니다

```
모델    gpt-image-1-mini
        gpt-image-1 / 1.5 / 2 는 이 조직에서 한도 0 (429)
n       3장 · 약 15초
포맷    webp 압축 70 → 장당 150~300KB (png는 2.3MB)
```

덱 04·22번의 이미지는 **목업이 아니라 이 파이프라인의 실제 출력**이다.
한도가 풀리면 `lib/ai.ts`의 `IMAGE_MODEL` 한 줄만 되돌리면 된다.

**논증 사슬** — 이게 척추다.

```
가격대가 중간이다  →  매일 쓸 수 있다  →  매일 쓰면 상한다
                 →  3대장은 안 상하고, 매스는 버린다
                 →  이 구간에만 "상함을 어떻게 다룰까"가 남는다
                 →  지우지 말고 나의 것으로  →  킨츠기 · Dapper Dan
                 →  REMADE
```

킨츠기를 문화 비유로 먼저 꺼내지 않는다. **포지셔닝에서 문제를 도출한 다음** 답으로 꺼낸다.

**진술 슬라이드는 절대 줄이지 않는다.** 그게 논증의 관절이다.
넘치면 15 · 21 · 31을 줄인다.

## 디자인

레퍼런스(2Planner IR)의 구조를 따르되 팔레트를 MCM으로 옮겼다.

- 본문 다크 `#12100E` + 코냑 글로우, 챕터 구분은 라이트 `#F4F1EC`
- 액센트 코냑 `#C4915F`
- 반투명 도형으로 글로우를 만들면 경계가 보인다. 그래서 배경은 **이미지**다
- 폰트 **Apple SD Gothic Neo**. 웨이트가 9단계라 한글 대비가 산다.
  PDF에 임베드되므로 배포는 문제없다. PPTX 편집은 맥 기준
- **박스를 쓰지 않는다.** 카드·테두리 대신 여백과 0.75pt 헤어라인으로만 나눈다.
  잡스 덱에 사각형 카드가 없는 이유와 같다 — 테두리가 늘면 시선이 갈 곳을 잃는다
- **강조는 색이 아니라 크기로 한다.** 48pt Bold 옆의 15pt Regular는 색을 바꿀 필요가 없다
- 타입 스케일 — 진술 48 / 헤드라인 34 / 항목 24 / 본문 14 / 캡션 11


```bash
osascript -e 'tell application "Keynote"
  set d to open POSIX file "'$PWD'/MCM_Luxury_Book_IR.pptx"
  delay 2
  export d to POSIX file "'$PWD'/MCM_Luxury_Book_IR.pdf" as PDF
  close d saving no
end tell'
```

## 발표 전 확인

- [ ] 시장 규모를 물으면 **"산정 중"**이라고 답한다. 숫자를 지어내지 않는다
- [ ] "2027년 의무화"라고 말하지 않는다. **위임법 2027, 시행 2028~29**
- [ ] 신사임당은 **전해지는 일화**다. 사료처럼 말하지 않는다
- [ ] **"AI가 장인을 대체한다"로 읽히지 않게** 먼저 선을 긋는다. AI는 시안까지
- [ ] `care_score`는 규칙 기반 계산이다. **"AI 상태 분석"이라 말하지 않는다**
- [ ] MCM 실적 하락 수치를 **먼저 꺼내지 않는다**
- [ ] Archive Style은 **미구현**. "다음 단계"로 말한다


## 캡처를 다시 뽑는 방법

인증이 걸린 화면이라 로그인 세션이 필요하다. 자격증명은 브라우저 창에만 넣는다.

```bash
node capture.mjs     # Chrome 창이 열린다. 거기서 로그인하면 6장을 알아서 찍는다
```

카메라 뷰파인더는 캡처하지 않는다 — 헤드리스 Chrome은 가짜 스트림을 물어서
실제 화면이 안 나온다. 대신 **스캔 결과인 언박싱 화면**을 쓴다. 정보도 그쪽이 많다.
