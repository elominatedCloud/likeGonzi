# MCM Storybook 타이포그래피 감사

감사 일자: 2026-08-15
대상: 홈, 제품 상세, 제품 로그 타임라인
범위: 바텀 내비게이션을 제외한 타이포 위계, 글자 크기, 자간, 카피와 카드 반복감

## 결론

현재 화면은 색상과 소재감보다 타이포 시스템 때문에 생성형 UI처럼 보이는 편이다. 10–12px의 작은 보조 텍스트, 영문 대문자 라벨과 넓은 자간, 서로 다른 세리프 글꼴, 비슷한 둥근 카드가 동시에 반복되면서 사람이 편집한 브랜드 화면보다 템플릿을 조합한 인상을 준다.

## 캡처 단계

1. 홈 — 수정 필요
   - 증거: `01-home-mobile.png`
   - `CARE REMINDER`, `GOLD MEMBER BENEFIT`, `VISION 2030`, `AI STORYBOOK`이 모두 10px와 1.2–1.4px 자간을 사용한다.
   - 카드마다 같은 `eyebrow → 굵은 제목 → 작은 설명` 문법이 반복되어 콘텐츠 중요도가 모두 비슷해 보인다.
   - 한국어 본문도 12px가 많아 정보량에 비해 읽기 피로가 크다.

2. 제품 상세 — 수정 필요
   - 증거: `02-product-detail-mobile.png`
   - 제품명은 Cormorant Garamond 28px, 페이지 제목은 같은 계열 17px인데, 섹션 라벨은 10–12px 대문자와 큰 자간으로 다시 바뀐다.
   - 인증, 시리얼, 쿠폰, 수선 이력, AI 설명이 10–12px에 몰려 중요도 구분이 약하다.
   - `MY STORYS`는 문법상 `MY STORIES`가 자연스럽다.
   - 수선 카드의 이미지가 깨져 대체 텍스트가 노출된다. 타이포 감사 범위 밖이지만 화면 완성도를 크게 떨어뜨리는 별도 QA 이슈다.

3. 로그 타임라인 — 보통, 세 화면 중 가장 안정적
   - 증거: `03-timeline-mobile.png`
   - 제목 24px, 탭 16px, 기록 제목 15px의 큰 위계는 비교적 명확하다.
   - 다만 제품명과 일부 설명에 Georgia 12px가 적용되고, 한국어 메모는 11px의 연한 회색이라 카드가 작고 흐릿하게 느껴진다.
   - 홈·제품 상세의 Cormorant와 달리 이 화면만 Georgia를 직접 사용해 화면 전환 시 브랜드 글꼴이 바뀐다.

## 가장 영향이 큰 수정

1. 글꼴을 두 계열로 제한한다.
   - 한국어와 모든 UI: Noto Sans KR 또는 Pretendard 중 하나만 사용
   - 영문 제품명과 제한된 브랜드 헤드라인: Cormorant Garamond만 사용
   - Abhaya Libre와 하드코딩된 Georgia는 핵심 화면에서 제거

2. 모바일 타입 스케일을 고정한다.
   - 제품명/브랜드 디스플레이: 26/32, 500
   - 페이지 제목: 24/32, 700
   - 섹션 제목: 17/24, 700
   - 본문: 14/22, 400
   - 보조 정보: 12/18, 500
   - 영문 eyebrow: 11/16, 600, 자간 0.08em 이하
   - 한국어에는 장식용 자간을 적용하지 않는다.

3. 작은 글자를 줄이는 대신 정보량을 편집한다.
   - 10px 본문과 설명을 12–14px로 올린다.
   - 카드마다 붙은 영문 라벨은 필요한 곳에만 남긴다.
   - 홈의 ESG·혜택·AI 카드는 같은 문법을 반복하지 말고, 핵심 행동이 있는 카드만 강조한다.

4. 카드 표현을 정리한다.
   - 모든 섹션에 동일한 큰 radius와 그림자를 쓰지 않는다.
   - 정보 그룹은 구분선이나 여백으로 묶고, 실제 행동이 있는 영역만 카드로 만든다.

## 접근성 위험과 확인 한계

- 10–11px의 연한 갈색·회색 텍스트는 실제 기기와 밝은 환경에서 식별성이 떨어질 가능성이 높다.
- `maximumScale: 1`은 사용자의 확대를 막으므로 저시력 사용성 측면에서 재검토가 필요하다.
- 이번 평가는 현재 모바일 화면 캡처와 계산된 CSS를 기준으로 했다. 키보드 이동, 스크린리더, 동적 글자 확대, 실제 명암비 수치는 별도 테스트가 필요하다.

## 권장 작업 순서

먼저 레이아웃을 건드리지 않고 전역 폰트와 타입 토큰을 정리한 뒤, 홈 → 제품 상세 → 로그 순서로 작은 글자와 영문 라벨을 치환한다. 그 다음 카드 수와 카피를 줄이는 편집 패스를 진행하는 것이 안전하다.
