## 7 · 해결 — 50초

```
H:  발견부터 다음 소유자까지, 하나의 타임라인
```

`B:`
```
 발견 ─ 구매 ─ 사용 ─ 관리 ─ 수선 ─ 물려주기
   └──────── 하나의 기록으로 이어진다 ────────┘
```
- 내가 남긴 기록과 **브랜드가 남긴 기록이 같은 줄에** 흐른다

`V:` 실제 타임라인 화면. 내 기록(사진)과 수선 기록이 번갈아 있는 컷.

`S:` "저희 답은 하나의 타임라인입니다.
핵심은 **내 기록과 브랜드의 기록이 같은 줄에 있다**는 점입니다.
사진 앱은 브랜드 기록을 못 갖고, 브랜드 시스템은 내 추억을 못 갖습니다.
이 두 개가 만나는 곳은 지금 아무 데도 없습니다."

## 8 · ★ AI가 하는 일 — 90초 (주제 직결, 최다 배분)

```
H:  AI는 쓰게 하지 않는다. 대신 써준다.
```

`B:`

| 단계 | 사용자가 하는 일 | **AI가 하는 일** | 상태 |
|---|---|---|---|
| 기록 | 사진 1장 + 상황 칩 탭 | **문장으로 만든다** — 장소·날짜·제품을 엮어 한 편의 글로 | ✅ 구현 |
| 축적 | 아무것도 안 함 | **Recap 생성** — 흩어진 기록을 하나의 이야기로 묶는다 | ✅ 구현 |
| **수선** | 부위 탭 + 사진 | **REMADE** — 손상 자리에 어울리는 문양 시안 3안 생성 | ◐ 스키마 준비 |
| **스타일링** | 시대 하나 선택 | **Archive Style** — 내 가방을 MCM 전성기 룩으로 스타일링 | ✳ 제안 |
| 인사이트 | 아무것도 안 함 | **패턴 도출** — 누가, 어떤 상황에, 어떤 제품을 | → 11번 |

`V:` 좌: 사용자가 사진 1장 올리는 화면 / 우: AI가 만든 문장. 화살표 하나.
실제 생성 결과를 그대로 띄운다.

`S:` "이게 저희가 주제에 답한 방식입니다.
기존 서비스는 사용자에게 **입력을 요구**했습니다. 저희는 반대로 갑니다.
사용자는 사진 한 장을 올리고 상황 칩 하나를 누릅니다. **문장은 AI가 씁니다.**
기록이 쌓이면 AI가 그걸 하나의 리캡으로 묶습니다.
그리고 수선입니다. 여기서 저희는 방향을 뒤집었습니다.

신사임당이 잔칫상에서 남의 치마에 튄 얼룩 위에 **포도를 그린** 이야기가 있습니다.
치마는 버려지지 않았고, 오히려 팔려서 새 치마 값이 됐습니다. **흠이 값이 된 겁니다.**

저희는 수선을 되돌리는 일로 보지 않습니다. **그 자리에 그립니다.**
AI가 손상 부위에 어울리는 문양 시안 세 개를 만들고, 실물은 MCM 장인이 만듭니다.
**AI가 손을 대체하지 않습니다. 시안까지입니다.**

그리고 이건 MCM의 역사이기도 합니다. 1988년 Dapper Dan이 비세토스를 뜯어 다시 꿰맨 것,
그게 이 브랜드를 아이콘으로 만들었습니다.

AI를 화려한 기능으로 쓰지 않았습니다. **기록의 마찰을 없애고, 손상을 서사로 바꾸는 데 썼습니다.**"

> ⚠ 정확히 말할 것
> - 구현됨: **AI Story 생성 · AI Recap 생성** (`gpt-4o-mini`, `product_recaps` 캐시)
> - 스키마만 준비: AI 리폼 이미지 (`repairs.ai_image_url`, `source='ai_custom'`)
> - **✳ 제안 단계: Archive Style** — 구현 안 됨. **"만들었다"고 말하지 말고 "다음 단계"로 말할 것.**
>   같은 이미지 생성 경로를 재사용하므로 새 테이블은 불필요
> - **"AI가 제품 상태를 분석"은 말하지 말 것** — `compute_care_score()`는 규칙 기반 계산이다.
>   (기본 70 + 기록당 3, 최대 12 + 수선당 6, 최대 12 + 최근 90일 활동 6, 상한 100)
>   **"등록된 기록으로 산출한다"**고 정확히 말하면 오히려 신뢰가 올라간다

그래서 저희 배경에서 이 마름모는 **바람에 흐릅니다.** 패턴을 원래 의미로 되돌린 겁니다.
로렐은 승리와 명예의 상징이라 정품 인증 배지에 썼습니다.
그리고 저희가 조사하다 발견한 게 있습니다. **MCM의 헤리티지는 뮌헨 럭셔리가 아니라 재해석입니다.**
1988년 Dapper Dan이 코냑 비세토스를 뜯어서 무대의상으로 다시 만들었고, 그게 이 브랜드를 아이콘으로 만들었습니다.
2020년에는 그 계보의 스타일리스트가 글로벌 크리에이티브 파트너가 됐습니다.
**MCM은 원래 사람들이 뜯어고치면서 커진 브랜드입니다.** 저희는 그 전통을 AI 스타일링으로 되살립니다.
그리고 마지막 줄이 가장 중요합니다 — **MCM은 이미 NFC와 블록체인 패스포트를 갖고 있습니다.
저희는 새 시스템을 제안하지 않습니다. 이미 있는 것 위에 경험을 얹습니다.**"

## 10 · 데모 — 90초

```
H:  매장에서 산 박스가 서비스의 시작점이다
```

`V:` 순서 고정
1. **박스 QR/NFC 스캔** → 스크롤에 따라 박스가 열린다 *(Challenge 02)*
2. 등록 → 타임라인 첫 줄 자동 생성 (**빈 화면을 한 번도 안 보여준다**)
3. 사진 1장 + 상황 칩 → **AI가 문장을 쓴다** *(Challenge 01)*
4. **수선 접수 — 제품 실사 위에서 부위를 직접 탭한다** → 증상 선택

`S:` "박스를 여는 속도는 사용자가 정합니다. 스크롤을 멈추면 애니메이션도 멈춥니다.
등록하면 구매 기록이 자동으로 첫 줄에 찍힙니다. 빈 타임라인은 절대 보여주지 않습니다.
사진 한 장을 올리면 AI가 문장을 씁니다.
그리고 이 화면이 저희가 가장 자신 있는 부분입니다 — **제품 사진 위에서 부위를 직접 누릅니다.**
글로 "왼쪽 아래 모서리가 까졌어요"라고 쓰는 게 아니라, 그 자리를 누릅니다.
그래서 이 데이터는 자유 서술이 아니라 좌표와 분류로 남고, **그대로 집계됩니다.**"

> 4번에 시간을 남길 것. ✅ **구현 완료** (`Components/care/AreaBoxPicker.tsx`)
> 좌표는 `lib/repair.ts`의 `AREA_BOX_SETS`. 실사 위 % 좌표라 반응형에서 그대로 스케일된다.
> **같은 좌표를 11번 슬라이드 히트맵이 재사용한다** — 누른 자리가 뜨거워지는 자리다.

## 11 · 데이터 자산 — 70초

```
H:  기록이 쌓이면, 브랜드가 몰랐던 것이 보인다
```
