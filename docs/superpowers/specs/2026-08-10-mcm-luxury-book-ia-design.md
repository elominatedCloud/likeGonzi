# MCM Luxury Book — IA & 스토리보드 설계

**작성일** 2026-08-10
**대상 회의** 8/13 (목)
**담당** 정운 (FE / 앱 설계)
**플랫폼** 반응형 웹

---

## 1. 한 줄 정의

**QR 스캔으로 시작해, 가방 하나의 일생을 한 줄의 타임라인으로 남기는 반응형 웹.**

린 캔버스의 문제 6번(사진은 SNS, 여행은 캘린더, 수선은 브랜드 내부에 흩어짐)을
**하나의 타임라인으로 합치는 것**이 이 서비스의 유일한 차별점이다.
나머지 기능(케어·쿠폰·샵)은 이 타임라인을 유지시키는 리텐션 장치다.

---

## 2. 확정 사항

| 항목 | 결정 |
|---|---|
| 진입점 | QR 스캔 (박스 부착). 첫 방문·제품 0개일 때만 자동 실행 |
| 글로벌 내비 | 하단 탭 5개 — 홈 / 로그 / [📷] / 샵 / 마이 |
| 카메라 | FAB 1개. QR ⇄ 기록 모드 토글 (인스타 카메라 패턴) |
| 로그 정의 | 가방과 함께한 **일상 기록** + **제품 이력**을 한 타임라인에 병합, 칩으로 필터 |
| 언박싱 | 별도 화면 아님. **단일 스크롤 페이지**, CSS 3D 힌지 회전 |
| 제품 소개 | 스펙 카드 아님. **매장 연출 실사 풀블리드** + 텍스트 오버레이 |
| 가입 게이트 | 언박싱 감상까지는 비회원 허용. 등록 시점에만 가입 요구 |

## 3. IA 트리

```

   0.1 QR 스캔                     첫 방문·제품 0개 → 자동 / 이후 FAB
       ├ unit QR      → 0.2 언박싱
       └ campaign QR  → 캠페인 랜딩 (소유 없음, 유입용)
   0.2 언박싱 스크롤 페이지         비회원 감상 가능
       박스 열림 → 카메라 하강 → 제품 등장 → 매장 연출 → 디테일 → sticky CTA

   ├ 멤버십 등급

   └ 설정
```

### 탭 설계 근거

스타벅스 탭 구조의 원리는 **행동 빈도순**이다. 페이가 2번인 이유는 매일 쓰기 때문.
럭셔리는 빈도 구조가 완전히 다르다.

| 행동 | 빈도 |
|---|---|
| 스토리 기록 (여행·기념일) | **월 1~수회** ← 최다 |
| 쿠폰·혜택 확인 | 월 1회 + 생일 |
| 케어 조회 | 계절마다 |
| QR 스캔 | 구매 시 1회 + 길거리 |
| 수선 | 연 1회 미만 |
| 구매 | 연 1~2회 |

→ 최다 빈도인 **기록**과 최고 임팩트인 **스캔**을 카메라 FAB 하나로 묶어 중앙에 배치.

## 4. 골든패스 스토리보드

`QR 스캔 → 인식 → 언박싱 스크롤 → 가입 → 온보딩 → 완료 → 홈`

**7컷 / 6라우트** — ①②는 같은 화면(카메라 위 바텀시트 상승)이라 라우트는 하나.

### ① QR 스캔
카메라 뷰 · 스캔 프레임 · 상단 안내("박스의 QR 코드를 비춰주세요")
하단 모드 토글 [QR 스캔][기록], 비회원이라 「기록」 비활성.
**자동 실행 조건: 첫 방문 AND 제품 0개.** 그 외에는 FAB로만 진입.
→ 3년 쓴 유저가 앱 열 때마다 카메라 뜨는 걸 막는다.

### ② 인식 · 정품 확인
카메라 위로 바텀시트 상승. 정품 배지 · 시리얼 · 제품명 · CTA「열어보기」.
`unit` QR이라 시리얼까지 잡힌다. `campaign` QR이면 이 컷 대신 캠페인 랜딩으로 분기.

### ③ 언박싱 스크롤 페이지 → 5장 참조

### ④ 멤버십 가입
헤드라인 "이 가방의 일생을 기록할 준비가 됐습니다"
소셜 3종(Google / Apple / Kakao) + 이메일. 하단 "가입 시 이 제품이 자동 등록됩니다".
**여정 전체에서 유일한 게이트.**

### ⑤ 온보딩 (2스텝, 건너뛰기 허용)
- 생일 → 매년 쿠폰·케어 서비스 발송 트리거
- 여행 스타일 칩 (도시 / 자연 / 출장 / 전시·미술관 / 페스티벌 / 캠핑)

**여행 라이프스타일 개인화의 유일한 데이터 소스.**
캘린더 연동 없이 칩 선택만으로 시작. 부족하면 로그 태그에서 추론 보강.

### ⑥ 등록 완료 · 첫 로그
체크 → 타임라인 첫 줄 자동 생성 `2026.08.05 · 구매 · 정품 등록`
그 아래 점선 노드로 다음 기록 유도.
**빈 타임라인을 절대 보여주지 않는다.**

### ⑦ 홈
인사 → 내 제품 그리드(+추가 슬롯) → 카드 3장.
카드 순서 = **케어 → 혜택 → 라이프스타일 제안**.
온보딩에서 고른 칩("출장")이 3번 카드로 즉시 회수돼야 개인화가 체감된다.

## 5. 언박싱 스크롤 페이지 (핵심)

화면이 아니라 **페이지 1장 + 스크롤 위치**. 스크롤을 멈추면 애니메이션도 멈춘다 —
사용자가 속도의 주인이 되는 게 "직접 열어본다"는 감각의 전부다.

### 5.1 구간 분배

| 스크롤 | 상태 | 연출 |
|---|---|---|
| 0% | 닫힌 박스, 위에서 내려다봄 | 제품명 숨김 — 미스터리가 스크롤 동기 |
| 30% | 뚜껑 −42° | 틈새로 빛. 아직 제품 안 보임 |
| 60% | 뚜껑 −84° (수직) | **연출 포인트.** 뚜껑이 선으로 사라지는 순간 |
| 85% | 뚜껑 −118°, 제품 상승 | 안쪽 면 노출. 카메라 눈높이로 하강 |
| 90% | 매장 연출 실사 풀블리드 | 텍스트가 사진 위에 얹힌 화보 |
| 100%+ | 디테일 · 스펙 · 착용 컷 | sticky CTA「내 것으로 등록하기」 |

−84° 지점에서 **뚜껑 회전과 카메라 하강을 겹치면** "박스를 내려다보다 → 제품과 마주 본다"로
시점이 자연스럽게 넘어간다.

### 5.1b 힌지 단면 (맥북 방식)

```
 0%              30%             60%             85%
                                                  ╲
                   ╱              ║                ╲
  ══════╗        ╱               ║                 ╲
 ┌──────┐      ┌──────┐        ┌──────┐        ┌──────┐
 │ 제품 │      │ 제품 │        │ 제품 │        │ 제품↑│
 └──────┘      └──────┘        └──────┘        └──────┘
  ▲
  힌지 = 안쪽 모서리 (transform-origin: top center)

 뚜껑   0°        −42°           −84°           −118°
 카메라 58°       58°            58°→           8°
```

**뚜껑과 카메라의 스크롤 구간이 다르다.** 뚜껑은 5~70%, 카메라는 50~90%.
겹치는 50~70% 구간에서 두 동작이 물리며 시점 전환이 일어난다.

### 5.2 구현 — CSS 3D 힌지, JS 0줄

맥북 뚜껑과 같은 방식. 힌지는 안쪽 모서리, `transform-origin: top center`.

```css
.unbox { height: 400vh; view-timeline: --box block; }
.stage { position: sticky; top: 0; height: 100vh;
         perspective: 620px; display: grid; place-items: center; }

.tilt  { transform-style: preserve-3d;              /* 카메라 */
         animation: camera linear both;
         animation-timeline: --box;
         animation-range: 50% 90%; }

.lid   { transform-origin: top center;              /* 힌지 */
         transform-style: preserve-3d;
         animation: open linear both;
         animation-timeline: --box;
         animation-range: 5% 70%; }

.prod  { animation: rise linear both;
         animation-timeline: --box;
         animation-range: 60% 95%; }

@keyframes open   { to { transform: rotateX(-118deg) } }
@keyframes camera { from { transform: rotateX(58deg) } to { transform: rotateX(8deg) } }
@keyframes rise   { to { transform: translateY(-40px) scale(1.35) } }
```

뚜껑 겉/안 두 면은 `backface-visibility: hidden` + 안쪽 면 `rotateX(180deg)`.

**폴백** — `@supports not (animation-timeline: view())` 안에서 IntersectionObserver로
단계별 클래스만 토글. 뚝뚝 끊겨도 서사는 산다. 약 30줄.

### 5.3 구현 방식 비교 (검토 기록)

| 방식 | 에셋 | iOS Safari | 판정 |
|---|---|---|---|
| **CSS 3D + scroll timeline** | **0장** | 안정 | **채택** |
| 레이어 PNG + scroll timeline | 투명 PNG 5장 | 안정 | 에셋 낭비 |
| 이미지 시퀀스 canvas 스크럽 | 30~60장 | 안정 | 과함 |
| `<video>` + currentTime 스크럽 | 영상 1개 | **버벅임 심함** | 탈락 |
| 자동재생 비디오 | 영상 1개 | 안정 | 몰입 약함 |

**박스가 코드가 되면 색·비율·로고 패턴을 제품마다 바꿔 끼울 수 있다.
제품 100종이어도 박스 에셋은 0장.** 이게 실사 비디오 대비 진짜 이득이다.

### QR 타입 상세 (1번 안건 배경)

- `unit` — 시리얼 1개 = QR 1개. 박스 부착. **개체 소유권 + 수선 이력 + 물려주기**가 여기 붙는다
- `campaign` — 길거리 스티커. 소유 없음. 제품 구경 → 가입 유도

`unit`이 없으면 "내 이 가방"이 성립하지 않아 타임라인 전체가 무너진다.
비용은 제품마다 고유 QR 인쇄. 기존 시리얼 체계가 있으면 그대로 매핑.

## 11. 이미지 생성 프롬프트 (실사 컷용)

박스·UI는 코드로 그리므로 실사가 필요한 건 **제품 컷뿐**이다.
아래는 시안(안정) 작업용 초안. 실제 제품 형태·비세토스 패턴은 AI로 재현되지 않으므로
**최종본은 MCM 공식 이미지 또는 직접 촬영으로 교체**하고, AI 생성분은 레이아웃 검증용으로만 쓴다.

공통 접미: `9:16 vertical, mobile full-bleed, generous negative space in upper third for text overlay, no text in image, photorealistic, 85mm, shallow depth of field`

**P-1 · 매장 연출 히어로** (스크롤 90%, 메인)
```
A luxury cognac-brown coated-canvas backpack displayed on a low matte-stone
plinth inside a minimalist boutique. Single warm key light from upper left,
soft falloff into a deep neutral background. Polished concrete floor with a
faint reflection. Museum-like, reverent, no props competing for attention.
```

**P-2 · 매장 연출 측면** (스크롤 95%)
```
Same backpack shot from a three-quarter rear angle on a brushed-brass stand,
backlit rim light separating the silhouette from a warm taupe wall.
Hardware and stitching catch the light. Editorial, quiet, expensive.
```

**P-3 · 여행 맥락** (디테일 섹션)
```
The same backpack resting on a hotel bench beside a folded linen jacket and
a boarding pass, morning window light raking across the surface.
Lived-in but immaculate. Suggests departure, not display.
```

**P-4 · 소재 클로즈업** (스펙 섹션)
```
Extreme macro of coated canvas grain meeting a leather trim edge,
visible stitch pitch and a brass rivet. Raking light to reveal texture depth.
Fills frame, no context.
```

**P-5 · 착용 컷** (하단)
```
Over-the-shoulder crop of a person wearing the backpack while walking through
a sunlit city street, shot from behind at hip height. Face not visible.
Motion blur in background, bag sharp. Documentary tone, not fashion editorial.
```

**P-6 · 제품 누끼** (언박싱 85% 구간에 삽입)
```
Product-only cutout of the backpack, front three-quarter view,
even soft studio light, pure white background, no shadow,
crisp edges suitable for transparent PNG extraction.
```

### 프롬프트 3줄 규칙

1. **상단 1/3 비우기** — 제품명 텍스트가 얹힌다
2. **소품 최소** — 시선 경쟁하면 제품이 죽는다
3. **P-3만 예외로 맥락 허용** — 여행 헤리티지가 캔버스 Value Prop이라 이 컷만 서사를 진다
