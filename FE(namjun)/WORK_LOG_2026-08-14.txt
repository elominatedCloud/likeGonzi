7. 새 기록 작성과 복수 상품 기록 구조
============================================================

진입 방식:
- 하단 카메라 버튼은 현재 이동이 막혀 있다.
- 카메라는 추후 다른 기능이 들어갈 예약 버튼이다.
- 공용 /log/record/new 라우트는 제거했다.
- 기록 작성은 각 상품 타임라인의 + 기록 추가 버튼으로만 진입한다.

작성 화면 기능:
- 현재 타임라인 상품은 기본 선택되며 해제할 수 없다.
- PRODUCT를 열면 내가 보유한 Stark, Ella, Pina 목록이 표시된다.
- 한 사진에 같이 나온 다른 상품을 추가로 복수 선택할 수 있다.
- 선택된 상품은 제품 썸네일 칩으로 화면에 표시된다.
- 사진 파일을 선택하면 미리보기가 바뀐다.
- 업로드 사진은 Data URL로 변환하여 저장 가능한 형태로 처리한다.
- 메모는 최대 100자이며 글자 수를 표시한다.
- 장소 변경은 Google Maps 검색을 새 탭으로 연다.
- AI 추천 보기는 작성 화면을 연 현재 상품의 추천 페이지로 이동한다.

복수 상품 저장 방식:
- 저장 시 SharedRecord 객체를 만든다.
- 하나의 SharedRecord에 선택된 모든 productIds를 저장한다.
- 날짜, 제목, 장소, 메모, 사진과 AI STORY를 함께 저장한다.
- localStorage의 likegonzi-shared-records 키에 기록을 추가한다.
- 저장 후 기록 작성을 시작한 상품의 전체 타임라인으로 이동한다.

여러 타임라인에 동시에 남는 방식:
- 각 TimelinePage는 localStorage의 공유 기록을 읽는다.
- 현재 productId가 SharedRecord.productIds에 포함되면 해당 기록을 표시한다.
- 예를 들어 Stark와 Ella를 함께 선택해 저장하면 같은 기록이 다음에 모두 나타난다.
  /log/stark/timeline
  /log/stark/timeline/my
  /log/ella/timeline
  /log/ella/timeline/my
- Pina가 선택되지 않았다면 Pina 타임라인에는 나타나지 않는다.
- 공유 기록 상세의 WITH에는 Stark와 Ella 두 상품이 모두 표시된다.

11. 내 기록 삭제 기능 추가
============================================================

요청 배경:
- 기록을 새로 추가할 수 있지만 기존 내 기록을 삭제할 방법이 없었다.
- 기본 제공 기록과 사용자가 만든 공유 기록 모두 상세 페이지에서 삭제할 수 있어야 했다.

수정한 핵심 파일:
- FE(namjun)/LogExperience.tsx
- FE(namjun)/log-experience.module.css

모든 내 기록 상세 페이지에 추가된 UI:
- 상세 화면의 스토리 다운로드 버튼 아래에 연한 붉은색 기록 삭제 배너를 추가했다.
- 배너에는 삭제 시 타임라인에서도 사라지고 복구할 수 없다는 안내를 표시한다.
- 오른쪽의 기록 삭제 버튼을 누르면 브라우저 확인 창을 먼저 표시한다.
- 사용자가 확인을 선택해야 실제 삭제가 진행된다.

기본 제공 기록 삭제 방식:
- localStorage의 likegonzi-deleted-records 키를 사용한다.
- 삭제 항목은 productId:recordId 형식으로 저장한다.
- 원본 TypeScript 데이터 자체를 손상하지 않고 사용자 브라우저에서 삭제 상태를 유지한다.
- TimelinePage는 삭제 목록을 읽어 기본 기록 중 삭제된 ID를 전체/내 기록 탭에서 제외한다.
- 제품 구매와 케어 이력에는 record id가 없으므로 내 기록 삭제 대상에 포함되지 않는다.

사용자 생성 공유 기록 삭제 방식:
- recordId가 shared-로 시작하는지 확인한다.
- localStorage의 likegonzi-shared-records에서 해당 SharedRecord 객체를 실제 제거한다.
- 하나의 기록이 Stark와 Ella처럼 여러 상품에 연결되어 있었다면 공유 원본이 제거되므로 두 상품의 전체/내 기록 타임라인에서 모두 사라진다.
- 삭제 후에는 삭제를 시작한 상품의 전체 타임라인으로 이동한다.

삭제 기능 적용 범위:
- Stark 성수 기록
- Stark 파리 기록
- Ella 재즈 기록
- Ella 갤러리 기록
- Pina 서점 기록
- Pina 미술관 기록
- 사용자가 새로 저장한 단일 상품 기록
- 사용자가 새로 저장한 복수 상품 공유 기록

삭제 후 화면 흐름:
1) 기록 상세 하단의 기록 삭제 선택
2) 복구 불가 확인 창 표시
3) 취소 시 아무 변화 없음
4) 확인 시 기본 기록은 삭제 목록 등록, 공유 기록은 저장 데이터 제거
5) 해당 상품 전체 타임라인으로 이동
6) 삭제 기록은 전체 타임라인과 내 기록 탭에서 표시되지 않음

관련 저장 키:
- likegonzi-shared-records: 사용자가 추가한 단일/복수 상품 기록
- likegonzi-deleted-records: 삭제 처리된 기본 내 기록 ID 목록
